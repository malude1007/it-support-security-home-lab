# Windows Support & Troubleshooting Lab
## Project Overview
This project documents practical Windows support and troubleshooting scenarios commonly handled in Help Desk, IT Support, Service Desk, and Desktop Support roles.

The goal is to demonstrate a structured troubleshooting approach, basic Windows administration skills, and clear technical documentation.

## Skills Practiced

- Windows troubleshooting
- Network connectivity diagnosis
- IP, DNS, and ping testing
- Software installation and basic error resolution
- Local user and permission management
- Printer troubleshooting
- Workstation health checks
- Technical documentation

## Lab Environment

- Windows 11 virtual machine
- VirtualBox
- Command Prompt
- Windows Settings
- Control Panel
- Device Manager
- Services
- Event Viewer where applicable

## Case Studies

1. Network Connectivity Issue
2. Software Installation and Configuration
3. Local Users and Permissions
4. Printer Troubleshooting
5. Initial Workstation Support Checklist

## Documentation Method

Each case includes:

- Issue description
- Symptoms
- Diagnostic steps
- Tools or commands used
- Root cause
- Resolution
- Validation
- Lessons learned
